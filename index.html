Theory

Bubble Sort

Bubble Sort compares adjacent elements and swaps them until the array is sorted.

Worked example

Example: 5, 3, 4 → 3, 4, 5 after repeated passes.

Core facts

Definition

Bubble Sort compares adjacent values and swaps them until the sequence is ordered.

Visualization

Repeated pass-by-pass comparison of neighboring bars with swaps highlights.

Complexity

O(n²) time, O(1) auxiliary space.

Related Algorithms

Insertion Sort, Selection Sort, Merge Sort, Quick Sort.

Key idea

  • Compare neighboring values.
  • Swap when the left value is larger.
  • Repeat until no swaps are needed.
